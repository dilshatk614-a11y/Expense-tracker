# Expense Tracker

A command-line Expense Tracker application built using Python and MySQL.

## Features

- Add Expense
- Add Category
- View All Expenses
- View Monthly Total
- View Spending by Category
- Exit the Application

## Technologies Used

- Python
- MySQL
- MySQL Connector

## Database

The project uses MySQL to store:

- Expense categories
- Amount spent
- Expense date
- Payment method

## How to Run

1. Install Python.
2. Install MySQL.
3. Create the database using the SQL file.
4. Install the MySQL Connector:

```bash
pip install mysql-connector-python
